# Slateory roadmap

Slateory focuses on solo creators planning videos across projects. This is a direction for discussion, not a delivery schedule.

## Available in the current source

- Separate projects with their own themes, ideas and optional YouTube setup.
- Theme filtering, reordering and progress tracking.
- Project-specific agent instructions with optional selected-card context.
- Educational Shorts, building in public and travel starter templates.
- Project backup/restore and browser-local storage.

## Retained but hidden

Bulk import code and tests remain in the source, but Paste ideas is currently hidden from the interface.

## Validate next

- Faster capture and comfortable editing on phones.
- Whole-workspace backup and clearer recovery guidance.
- A lightweight weekly review: what finished, what stalled and what to make next.

## Decisions that need evidence

Cross-device sync, native Android, publishing, collaboration and AI-generated content would expand the product substantially. Share your actual workflow before proposing one of these additions.

## Ways to help

Reproduce a bug, improve keyboard access, clarify a guide or suggest a template you would use. Use the repository's issue forms to explain the problem and current workaround. A roadmap item is not automatically an approved implementation task.
