GETTING STARTED

Plan your next video with Slateory.

One workspace for your themes, next ideas and completed videos. This guide uses a fictional creator planning a tutorial and a behind-the-scenes Reel.

1. Choose themes you will return to

A theme is a reusable topic bucket, such as Tutorials or Behind the scenes. Open the filter icon beside search and choose New theme to name a column, describe its purpose and choose a color. Begin with a few themes you can consistently make useful videos about.

2. Give each idea a concrete demonstration

Select New idea or the plus button in a theme. For a tutorial, “Show one useful spreadsheet shortcut” is a more actionable working title than “Spreadsheet tips.” Add what you will show, why it helps a viewer, production notes and a format: Reel + Short, YouTube tutorial, Reel + tutorial or Carousel. These are planning labels; Slateory does not generate the content.

3. Track the work you are actually doing

Change the status to In progress when you start production. Its border moves so the active card is easy to find. Mark it Complete after you finish; the card moves below the horizontal completed divider within its theme. You can restore a completed card to active work.

4. Make the sample board your own

On a fresh browser, Slateory opens with four sample themes and fourteen labelled cards. Edit and save a sample to keep it as your own. Start empty removes remaining samples and unused sample themes. Your own content stays. Use the immediate Undo control if needed.

5. Back up before moving browsers or devices

Select Export backup to download a JSON file containing your themes, ideas, notes, progress and linked video IDs. On the other browser, open Slateory, choose Restore a backup, select that file and review the replacement counts. Restoring replaces the current board; export it first if you want to keep it.

Storage belongs to your browser and website origin. It does not automatically sync between devices, browser profiles, localhost and GitHub Pages. The same domain’s other apps can share browser storage. Keep important backups somewhere safe.

6. Optionally connect your YouTube channel

Public videos: open YouTube setup and enter your channel ID, handle or channel URL plus your own YouTube Data API key. This loads public upload dates and public lifetime views, likes and comments. Restrict your key to YouTube Data API v3 and this website in Google Cloud. The key is session-only unless you choose to remember it on this device.

My channel + analytics: provide your own Google OAuth web client and connect the account that owns the channel. Read-only access can retrieve scheduled uploads and private period reports for linked public videos. Link a video’s URL or ID in its idea card and refresh to fetch its report.

Use the refresh button when you need updated data. A reload shows the saved snapshot. Public lifetime totals and private period reports cover different windows; compare like with like. API keys and Google tokens are never part of your board backup.

Separate projects

Use the left project dropdown to create or switch projects. Rename using the pencil beside the heading; changes save on Enter or when leaving the field. The adjacent trash icon deletes a project after confirmation. Deleting the last project leaves a fresh empty board. New projects start empty; your original board stays in Content board. Each project has its own themes, ideas, YouTube settings and cached reports. Appearance is shared. Switching projects clears the in-memory Google session and session-only API key, so reconnect to refresh private reports.

What Slateory does not do

Slateory does not upload videos, create schedules, publish to Instagram, guarantee reach, or provide cloud backup. A clock in the calendar represents a schedule already fetched from YouTube. You can plan without connecting any external service.
