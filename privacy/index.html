PRIVACY & DATA

Your content, in your browser.

Slateory is a browser-based planner. It has no Slateory account system or application server that receives your board content.

Where your board is stored

Themes, ideas, notes, statuses, appearance, YouTube settings and cached responses are stored in this website origin’s IndexedDB. Storage is specific to the browser and device; it is not cloud synchronization. Browser storage is not encrypted by Slateory. Other scripts on the same origin can access it. Clearing site data or browser storage eviction can remove it.

What a backup contains

Exported JSON backups contain your board content and linked video IDs. They exclude API keys, Google tokens, connection settings and fetched analytics. Importing a backup reads it locally in your browser and replaces only the current project’s board. Other projects are unchanged. Export each project separately. It does not publish the file to GitHub or make it visible to other visitors.

Optional Google connections

Public YouTube data requires your own API key. It stays in memory unless you choose Remember this API key on this device, which saves it in IndexedDB. Owner sign-in requests YouTube account read-only and YouTube Analytics read-only permissions. It cannot upload, edit or delete videos. Google tokens stay in memory and require reconnection after reload or expiry. Google receives the API and sign-in requests; YouTube thumbnail previews may load from Google.

Saved reports and deletion

Dated YouTube responses are cached for up to 30 days and removed on the next check after expiry. Sync is manual. Clear saved YouTube data removes the cache. Disconnect removes the token and saved API key but retains unexpired cached reports. Revoke Google access also clears the cache. You can manage grants through Google Account connections.

Hosting and measurement

GitHub Pages serves the application and may process ordinary page-request logs under its own policies. Slateory does not include advertising, visitor tracking scripts or an analytics pixel. The optional YouTube reports describe your linked videos; they do not track visitors to this website.

Each deployment operator supplies their own Google configuration. Review the YouTube terms and Google privacy policy before connecting. For the complete in-app notice, see How this board uses data. For product questions, open a GitHub issue without including credentials or private reports.
