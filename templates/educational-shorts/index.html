FREE CONTENT PLANNING TEMPLATE

Educational Shorts planning board.

Turn one useful lesson into a demonstration viewers can try.

This free starter contains three themes and four editable ideas. The examples below are exercises, not claims about your work, published videos or results. Replace them with material you can demonstrate from your own experience.

Use this template →

Show how

Teach a small task from start to finish.

One messy input, one useful output

What to show: Choose a task you know well. Show the original input, the two important actions and the finished output.

Value for viewers: Viewers can repeat one complete task instead of copying disconnected tips.

Production note: Replace this example with your subject. Use a fictional or permission-cleared input.

The step beginners usually skip

What to show: Record the same task with and without one check. Put the resulting difference side by side.

Value for viewers: Viewers learn when the extra step matters and how to perform it.

Production note: Choose a mistake you can reproduce. Avoid claiming everyone makes it.

Explain why

Make one confusing detail visible.

Same instruction, two different results

What to show: Change one input or setting while keeping the rest identical. Point to exactly what changes.

Value for viewers: Viewers learn a cause-and-effect relationship they can recognize later.

Production note: State which conditions stayed the same and one limit of the comparison.

Check understanding

Give viewers a way to test the lesson.

Can you spot the broken example?

What to show: Show two short examples. Pause briefly, then reveal the error and demonstrate the check that catches it.

Value for viewers: Viewers practice checking their understanding, with the full answer in this video.

Production note: Make the difference readable on a phone. Do not hide the answer in a follow-up.

Make this board your own

The button opens a preview in Slateory. Name and confirm the new project before anything is saved. All four ideas start as Suggested; edit them, choose a format and mark work In progress when you start production. Completed cards move below the shared divider.

Your existing projects stay unchanged. No YouTube connection is copied into this project, and planning works without an API key. Content is stored in this browser, with JSON export and restore for backups. It does not automatically sync to your phone or another computer.
